# Contributing

This repository keeps changes small, reviewable, and aligned with the shipped `paseo-workflow` behavior.

## Contribution flow

1. Create a focused branch from `main`.
2. Make one bounded change and keep the guide consistent with the upstream source of truth.
3. Validate the affected HTML, CSS, or JavaScript locally when applicable.
4. Open a pull request that explains the scope, validation, and any upstream assumptions.
5. Merge only after the final diff matches the intended change.

## Collaborative changes

When a change is genuinely produced by more than one contributor, preserve that collaboration in Git history with Git's standard `Co-authored-by:` trailer. Use an email address that is associated with the collaborator's GitHub account so GitHub can attribute the contribution correctly.

Agent-assisted work should still keep human-readable commit messages, bounded scope, and a clear source-of-truth reference.
